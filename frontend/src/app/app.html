About the Project

A Shift-Reduce Parser Simulator (SLR1) is a tool that demonstrates bottom-up parsing, a technique widely used in real compilers but rarely implemented hands-on due to its complexity.

It works on a fixed arithmetic grammar using a pre-derived, hardcoded SLR(1) ACTION/GOTO table instead of building a full LR-table generator.

The simulator begins with a lexical analyzer that converts an input expression into a stream of tokens. It then uses a parser stack and the SLR(1) table to repeatedly perform shift, reduce, accept, or error actions until the input is fully parsed or an error is detected.

Alongside parsing, it builds a symbol table, recording each identifier's name, type, and order of appearance, and performs basic semantic checks like flagging undeclared identifiers. During reduce actions, it also generates three-address code (TAC) using temporary variables.

Each parsing step is visualized through a step-by-step trace showing the stack state, input buffer, and action taken. This links syntax analysis to semantic analysis and code generation.
